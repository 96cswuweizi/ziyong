首次使用：创建 GitHub Token（约 2 分钟）

  1. 登录 GitHub，点右上角头像 → Settings
  2. 左侧最底部 Developer settings → Personal access tokens → Fine-grained tokens
  3. 点 Generate new token，名字随意填（如 网站后台），过期时间可选长一些或 No expiration
  4. Repository access 选 Only select repositories，只勾选你的网站仓库
  5. Permissions 里找到 Contents，选 Read and write（其他权限都不用给）
  6. 点生成，复制 github_pat_ 开头的 Token，回到本页「连接配置」里粘贴保存
日常使用流程：
① 打开 你的域名/admin.html → ② 写文章 / 加工具 / 传图片 → ③ 点保存发布 → ④ 等约 1 分钟，Cloudflare 自动更新网站。
手机浏览器也能用，配置需在每台设备上分别填一次。
安全说明：
· 本后台是纯静态页面，没有后端，Token 只存在你自己浏览器的 localStorage 里；
· 别人即使打开这个页面，没有你的 Token 也无法做任何操作；
· Token 只授予了本仓库的 Contents 读写权限，即使泄露也无法动你其他东西；
· 在公共电脑上用完后，请回「连接配置」点「清除本机 Token」。
数据存在哪里？
· 工具列表 → data/tools.json　· 文章列表 → data/blog.json
· 文章正文 → posts/*.md　· 图片 → images/
全部就是 GitHub 仓库里的文件，任何工具（GitHub 网页、git 命令）都能直接改，后台只是让你改得更省事。
