# 欢迎使用后台发布系统

这篇文章是通过 **admin.html 管理后台** 一键发布的示例，你可以在后台里随时编辑或删除它。

## 你能做到什么

- **写博客**：在后台填写标题、标签、摘要，正文用 markdown 书写，点"发布"即可
- **加工具**：在"工具管理"里填名称和链接，保存后工具页自动更新
- **传图片**：上传图片后把返回的路径粘贴到文章里，例如：

![示例图片](images/logo.png)

## markdown 常用语法

**加粗**、*斜体*、[链接](https://github.com)、`行内代码`：

```javascript
console.log('Hello, 博客!');
```

> 引用：写作是一件很酷的事。

| 语法 | 效果 |
| --- | --- |
| `# 标题` | 一级标题 |
| `- 列表` | 无序列表 |

## 发布流程

1. 打开 `你的域名/admin.html`
2. 粘贴 GitHub Token（只需配置一次）
3. 写文章 → 发布 → 约 1 分钟后 Cloudflare 自动上线

Enjoy!
