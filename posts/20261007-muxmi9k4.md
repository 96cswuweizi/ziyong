# Windows 10 专业版 KMS激活教程

这篇文章介绍了如何使用系统自带的 `slmgr` 命令，通过 KMS 服务器快速激活 Windows 系统。

> 2. 如果你在生产环境或日常中使用，建议支持正版，通过官方渠道购买合法授权。

## 你能做到什么

- **快速激活**：无需下载第三方软件，直接使用 Windows 自带命令提示符完成激活
- **自动续期**：KMS 激活有效期为 180 天，只要联网系统会自动连接服务器完成续期
- **多版本支持**：支持 Windows 10/11 专业版、企业版、教育版等多种版本

## 相关命令

在管理员 CMD 窗口中依次运行以下命令：

**卸载旧密钥**、*安装 GVLK 密钥*、`设置服务器`与`执行激活`：

```cmd
slmgr.vbs /upk
slmgr /ipk W269N-WFGWX-YVC9B-4J6C9-T83GX
slmgr /skms zh.us.to
slmgr /ato
